Claude Code, with a real UI.

Rift is a native desktop coding assistant powered by Claude. It works directly in your local project folder — reading files, searching code, running git, all on your machine. No servers, no sync. Just a fast, polished app that turns Claude Code into something you'd want to look at all day.

Download for Windows Latest release

Works in your real workspace

Opens your actual project folder — reads files, searches code, and runs git directly where you work.

Multi-tab chats

Run parallel conversations, each with its own model and effort level tuned to the task.

In-app browser dock

Preview local dev servers, deployed pages, and docs side by side with the chat.

Voice input

Speak your prompts with built-in speech-to-text when typing slows you down.

Fully local

Everything runs on your machine. No remote connections, no sync, no data leaving your device.

Auto-updating

One-click, unattended updates keep you on the latest build without a manual reinstall.
