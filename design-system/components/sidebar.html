Sidebar — the C+ switcher-led rail

The left rail is switcher-led: a Linear-style project switcher headlines it, the destinations that used to stack as full rows collapse into a compact footer icon strip, and the conversation list owns nearly the whole height. Order top-to-bottom: switcher → action row → scope segment → conversation list → footer icon nav → status strip. Everything stays in the rail's soft, low-saturation language — accent appears only in the monogram, branch pill, active row bar, and the New-chat surface. Anatomy

  1. Project switcher — monogram + name + live branch pill (name only; the app exposes no clean/dirty signal) + chevron. Click opens a portaled dropdown: All projects · every project (active ✓) · New project. Preserves the old ProjectRail affordances — open-focused, open-in-split (right-click), drag-a-project-to-a-pane.
  2. Action row — New chat reads primary via an accent-tinted surface (not a saturated slab) + Ctrl N keycap, sharing the row with a search icon-button that opens the command palette (Ctrl K).
  3. Scope segment — This project / All with a live chat count that mirrors the list's own filter.
  4. Conversation list — Pinned rows carry a faint accent wash + pin glyph; the most-recent day renders flat (no header) and everything older tucks behind one quiet Show earlier. Active row gets an accent bar; a working row shows a 3×3 dot-grid shimmer; hover swaps the timestamp for pin + more (rename/delete behind ⋯). Deeper buckets get sticky group headers.
  5. Footer icon nav — the destinations that once stacked as full rows collapse to a compact icon strip: Workspace · Chat · AI Health. Active tab tints accent.
  6. Status strip — identity monogram + active model + a live connection dot + Settings one click away. No user name/plan (Anthropic exposes none), so the monogram is a generic identity mark.
