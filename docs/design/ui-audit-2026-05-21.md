# Rift UI/UX Audit — 2026-05-21

> Surface audit driven via CDP screenshots of the running dev build (v0.4.21-alpha + uncommitted S126/S127). Covers 9 workspaces. Backend organization audit not yet done — captured below as a follow-up. Screenshots saved to `scripts/cdp/.audit/`.

## Scope captured

Confirmed visual review of: chat empty, sync, conflicts, files (TwoPane), activity, diagnostics, terminal, history, settings → Terminal tab. **Not viewed:** settings sub-tabs (Appearance / Assistant / Accessibility / Speech / Servers / SSH keys / About), chat with messages, split-pane mode.

---

## P0 — high-impact, low-effort

### 1. Flip activity bar to the left side
The workspace switcher rail lives on the RIGHT in every screen. Every comparable tool (VS Code, Linear, Discord, Slack, Cursor) puts it on the left. The eye lands on it last after parsing the workspace. Either flip it or make placement a setting (default left).

**Files:** `src/lib/components/shell/ActivityBar.svelte`, parent grid in `AppShell.svelte`.

### 2. Status bar carries serious meaning at invisible font size
`● Watching · last scan 16m ago · bridge · v0.4.21-alpha` is the only place "sync is working" is communicated, but it reads like ambient noise. Two wins:
- Make the dot tone-coded (green=watching live, yellow=stale >5min, red=stopped) and ~2px larger
- Move "last scan Xm ago" into the connection chip at the top so staleness reads from where the eye lives. Footer keeps version + bridge status only.

### 3. Two-stacked-titlebars effect
Top strip = window chrome (Rift / connection chip / txAdmin / window controls). Below = workspace header. They share zero visual language and aren't separated by accent. Add a 1px divider with `--border` between them, OR unify by pulling the workspace title icon into the same strip as the connection chip.

### 4. Sync header has three sync-adjacent affordances within 60px
`[…]` kebab + circular-refresh icon + big purple `🔁 Sync` button all live in the top-right of the Sync workspace. Most users won't know:
- Kebab = ?
- Icon-refresh = ?
- Big button = ?

Recommendation: keep the big button + kebab, drop the standalone refresh icon (it's a duplicate of one of the kebab menu items).

### 5. Watched-folders table is 8 rows of `0 · — · —`
"FILES / LAST / LOCKS" columns proudly display empty data. Either:
- Show real values (file count is presumably tracked — what does "0" actually mean here?)
- OR collapse the columns to "Status" with a single chip per row (`✓ idle`, `⟳ watching`, `⚠ stale`)

Right now the table looks like the feature is broken. **File:** `src/lib/components/sync/SyncPage.svelte`.

## P1 — meaningful polish

### 6. Empty states are gorgeous but copy-pasted
Conflicts / Activity / Sync's Recent-Activity / Chat-empty all use the same centered-icon + bold title + subtitle pattern. Good once, monotonous five times. Differentiate at least:
- **Chat empty** — keep the sparkle + suggestion cards (it's the most-seen)
- **Conflicts** — slim it to a single inline "All in sync" pill in the header so the void below doesn't dominate
- **Activity / Recent activity** — move the empty-state copy into the table itself as a single grayed row, not a centerpiece

### 7. Chat empty: server card is redundant
The "Endure RP / Synced workspace · 192.168.1.170 / [Switch]" card on chat-empty duplicates the connection chip in the top bar. Two places to see the same info on every new chat is wasteful. Drop the card, or replace it with something more useful (last-N-recent conversations as quick-resume tiles).

### 8. Diagnostics is dense; group the KPIs
13 KPI cards in a flat 7-column grid. The eye has no entry point. Group into 3 sections w/ subheaders:
- **Sync engine** (Auto-sync, Watching, Queue, Failed, Dropped)
- **Conflicts & locks** (Conflicts, Locks, Ignored)
- **Drift activity** (Last remote scan, Pulled, Last rescan, Last drift, Bus lag, Total emitted)

Same content, ~3× easier to scan. **File:** `src/lib/components/diagnostics/Diagnostics.svelte`.

### 9. Files: breadcrumbs are noisy
`C:\ \ Users \ BLAZZER \ Desktop \ FiveM Server \ txData \ Qbox_F8F761.base \ resources` is 8 backslash separators. Use `›` chevrons (already a UI convention) and let the leading `C:\` collapse on overflow. Same for the remote path. **File:** `src/lib/components/browser/LocalPane.svelte` / `RemotePane.svelte`.

### 10. Files: no diff hinting between panes
The two-pane file browser doesn't tell you which files differ at a glance. A small dot per row would be transformative:
- ● green = identical both sides
- ● yellow = exists both sides, different mtime/size
- ● gray = exists one side only

Drift logic already runs in the backend (`drift_scanner.rs`); plumb the row-level verdict to the file rows.

### 11. History list lacks structure
46 rows of `title / model · N msg · timestamp` with zero grouping. Even basic date grouping (Today / Yesterday / This week / Older) would slash scan time. Also: many titles are autogenerated junk ("Token-A. Reply OK-A.", "ACK-ONE now. Reply GOT-ONE.") — those are clearly debug/test convos. A small "Hide tests" filter (heuristic: title matches a regex like `/^(token-?[a-z]|ack-?one|memorize)/i`) would clean this up without losing data.

### 12. Composer placeholder is too loud
`Ask Claude — paste images, or type / for commands` front-loads "Ask Claude" then crams two hints. The hints already have a discoverable `?` icon next to the mic. Trim placeholder to `Ask Claude` and let the tooltip explain.

## P2 — nice-to-have

### 13. The `16` badge on history rail icon
History shows a cyan `16` badge that visually reads like an alert (cyan stands out against the rail). It's just the conversation count. Either drop the badge entirely (count is shown in the workspace header `History 16 conversations`) or de-emphasize it (smaller, muted gray, only show if count > 0).

### 14. Settings nav is undersized
The left-column settings nav (Appearance / Terminal / Assistant / Accessibility / Speech / Servers / SSH keys / About) feels narrow next to the wide content area. Either widen the nav for breathing room or use a horizontal tab strip across the top of the workspace.

### 15. "Reset" button placement on settings sub-pages
`Reset` floats at the top-right of the Terminal settings page next to the title. It's a destructive action — should be at the bottom OR live behind a confirm. Top-right is muscle-memory territory for "Save".

### 16. Pause/Clear pattern in headers
Activity and Diagnostics both expose `Pause` / `Clear` in the top-right with the same pill style. Good consistency — keep this. Other workspaces should adopt the same pattern (Files has Refresh / Filter; Conflicts has nothing — both miss a chance for "Pause auto-rescan").

---

## Cross-cutting recommendations

- **Establish a header pattern doc.** Every workspace renders header with title + icon, but the right-side actions are wildly inconsistent (Sync has 3, Conflicts has 0, Diagnostics has 2, History has 1). Pick a slot system: `[primary-action] [secondary-icons] [kebab]` and enforce it.
- **Tone-color the connection chip.** Currently green = connected, but staleness, drift count, conflict count are spread across the rail badges. Roll them into the chip: `🟢 Endure RP · 2 drift · 0 conflicts` so the topbar = system-health-at-a-glance.
- **The dot-only "Watching" indicator should match the chip.** If they're both green most of the time, give them shared visual language.
