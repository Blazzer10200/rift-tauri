# UI Enhancement Audit — 2026-06-09

Live CDP audit of v0.8.14 (Fable 5 session). 10 surfaces captured: Home, chat conversation,
empty chat, slash menu, Ctrl+K palette, model picker, Settings/Appearance, Harness telemetry,
Cost cockpit, composer states. Token system (`src/app.css`) reviewed.

**Verdict:** foundation is strong — OKLCH tokens, motion vocabulary, elevation stack, polished
Settings + Cost cockpit, excellent Ctrl+K palette. Remaining work = refinement tier (info
density, consistency, rough edges), not redesign.

---

## Top tier — daily-visible, low-to-medium effort

### 1. Activity rail "Steps" entries are information-dead
Every visible row renders `cd "C:/AI Workflow/project…` — the `cd` prefix consumes full width;
all 82 steps look identical.
- Strip leading `cd <path> &&`, show the real command verb.
- Middle-truncate, keep the tail (the meaningful part).
- Vary icon by tool type (read/grep/edit/git/bash) like inline chips already do.
- Bonus: group steps under collapsible per-turn headers instead of one flat list.
- **Highest value fix** — rail is on screen constantly, currently tells you nothing.

### 2. Slash menu ≠ command palette (same concept, two designs)
`/` menu = full-composer-width (~1000px) flat rows: monospace name + gray description, no
icons, no kbd hints, no match highlighting. Ctrl+K palette already nails this (icons, groups,
selected state, footer hints).
- Reuse palette design language: ~420px popover anchored left, icons, bold matched substring,
  grouped commands.
- File: `src/lib/components/assistant/Composer.svelte`.

### 3. Empty Activity rail costs ~23% of window for one sentence
Fresh chat = giant empty panel.
- Auto-collapse when no activity; slide in on first tool call.
- Or: ghost skeleton sections (Steps / Outputs placeholders) so the space previews its purpose.

### 4. Content hides behind the floating composer
Conversation view: amber-bordered block clipped behind the composer pill.
- Scroll container needs bottom padding / `scroll-padding-bottom` equal to composer height so
  the last message never gets buried.

### 5. Model stickiness is surprising
Opening an old Opus 4.8 chat rewrote the model for *new* chats (home quick-ask pill + new-tab
composer both flipped; "Model switched mid-conversation" toast fired).
- Opening a conversation should scope its model to that chat only.
- New-chat default should change only on explicit pick.

## Second tier — info density + chart polish

### 6. "Jump back in" / "Pick up where you left off" rows are title-only
- Add one-line last-message snippet (`--fg-subtle`) + small model chip per row.
- Ctrl+K palette already shows `opus · 16 msg` — same data, reuse it.

### 7. Cost cockpit charts don't handle sparse data
- "Daily spend": 6 tiny bars clustered in corner of a huge card. Scale bar width to visible
  date range (w/ empty-day ticks) or cap card height.
- Budget card: large dead zone under plan picker. Move Monthly/Weekly/Daily segmented inline
  w/ plan cards, or add spend-vs-budget sparkline.
- Files: `src/lib/components/` cost cockpit components (backend `src-tauri/src/usage/`).

### 8. Zero-state inconsistencies in Harness KPI band
- Output speed `—`, cache hit `0%`, turns `0` — three different "no data yet" semantics in one
  band. Pick one (dim `—` until first turn).
- Model pill reads `opus· medium` — missing space before separator.

### 9. User turns have no visual container
Both roles render flat text + label; dialogue rhythm depends on reading labels.
- Subtle `--bg-inset` card or 2px accent-soft left bar on user turns — scannable turn
  boundaries w/o breaking the Linear look.
- File: `src/lib/components/assistant/MessageBubble.svelte`.

### 10. Insight card ("Rift noticed…") severity styling inconsistent
First card has amber left border; siblings borderless w/ colored dots.
- If border encodes severity → all cards carry their stripe. If not → drop it.

## Bigger bets — design pass before building

### 11. Rich inline diff from Outputs
Rail shows `RiftTour.tsx +332 −312` w/ "Diff" toggle. If that doesn't already open a proper
side-by-side/unified diff viewer, it's the most differentiating feature available — an agentic
editor lives and dies on reviewability of edits.

### 12. Tool chip expand affordance
`›` expander is ~10px target, no hover treatment. Closed state under-advertises that it's
expandable. File: `src/lib/components/assistant/ToolChip.svelte`.

### 13. Merge tab strip into titlebar row (VS Code style)
Reclaims ~48px vertical. Medium-risk (centered search field in titlebar) — lowest priority.
