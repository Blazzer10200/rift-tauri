## v0.4.19-alpha — 2026-05-20 — S122 sync rebuild-detection + assistant UI polish

**Sync engine — rebuild-loop kill (3).** Three converging fixes against the Vite/Webpack/esbuild content-hashed-filename rebuild churn that was generating one `.rift-conflict.*` artifact per build cycle. **(1) `.rift-rebuild` sentinel.** Tooling-cooperative path: drop a `.rift-rebuild` file (any contents) at a watched-folder root before a build; while its mtime is <5min old, `drift_scanner::scan_folder` skips the folder entirely (no `ToPull`/`ToDelete` classification) AND `auto_sync::queue_path` suppresses all FS events for that root (no propagation of mid-build unlinks). Remove the sentinel post-build → normal sync resumes on the next event/scan. Stale leftovers (>5min) auto-ignored so a crashed build script can't lock sync forever. New `is_rebuild_sentinel_fresh()` helper in `drift_scanner.rs` (exported, consumed by both scanner + watch loop). New `REBUILD_SENTINEL_MAX_AGE_SECS = 300`. **(2) Zero-config rebuild-detection heuristic.** Recognizes hashed-asset filenames matching `<prefix>-<hash≥6chars>.<ext>` (covers Vite/Webpack/esbuild/Rollup/Parcel defaults). When a `Created`/`Modified` event lands with a hashed signature, `queue_path` scans the dirty queue for sibling `Deleted` entries in the same dir with the same `(prefix, ext)` and `first_seen` within 1500ms — drops them as the unlink-then-write rebuild fingerprint. Files without a `-` separator or with a short suffix (`app-v2.js`) never match, so no false positives on hand-named files. New `hashed_filename_signature()` + `REBUILD_PAIR_WINDOW_MS = 1500` in `auto_sync/watch.rs`. **(3) Failed-slot periodic retry.** Pre-fix, a `failed` entry's `next_retry` would expire but nothing promoted it back to `dirty` until the user clicked Push again — stuck-`failed: 1` indefinitely. The existing 5s root-vanish poll (`auto_sync.rs`) now also walks `self.failed`; when any entry's `next_retry ≤ now`, kicks `flush_all_now(None)` background-spawned. The promote loop inside `flush_all_now` already gates on backoff window — this just provides the missing heartbeat. Closes the build → conflict-file → indefinite-failed-slot loop on its own; the sentinel + heuristic prevent the conflict files from ever being created in the first place. Counters added: `ignored_by_rule["rift-rebuild"]` + `ignored_by_rule["rebuild-pair"]` surface through the existing diag pump.

**Assistant UI — chat lane polish (7).** **(1) Chat column widened.** New `--chat-col-max: min(1100px, calc(100% - 48px))` CSS var in `app.css`; consumed by `.messages` / `.composer-wrap` / `.hub` / `.alerts` / `.pane-focus-hint`. Was `min(960px, 88ch)` — `88ch` was the limiting term on Inter, producing a ~720px column at any viewport ≥1000px and leaving 880px of dead horizontal space at desktop widths. Column now hits 1100px at 1600vw + sits honestly centered (x=228 vs old x=417). Composer + status hub match. **(2) EditDiff collapsed by default in chat.** Diff blocks render as a one-line clickable header (`Edit ../src/lib/HUD.svelte  +1 -1 ▾`) instead of dumping the full diff body — large diffs were eating most of the message column for a turn that's already summarized in the header. Click chevron to expand, sticky once toggled. `untrack()`-wrapped initial value so prop reads don't fight user clicks. Compact (dock) variant stays expanded as before. **(3) Single-side diff → unified single column.** `+N -0` / `-N +0` blocks drop the empty BEFORE/AFTER column entirely instead of reserving half the width for whitespace. New `unified` + `unifiedSide` derived; `.diff-pair.single` grid + new red/green treatments mirror the side-by-side palette. **(4) Status hub merged into composer.** The "Sussing…" + elapsed-time row no longer renders as a separate card between messages and composer — folded into Composer's `.composer-shell` directly above the textarea. Shares border + background, only top corners rounded, `:has(:global(.hub))` squares the composer's top corners when present. Reads as one continuous element. `tabId` threaded through `AssistantPane → Composer → StatusHub` so split-pane independence is preserved. **(5) Stop button consolidated.** Dropped from the status hub (duplicate). Composer's existing Send→Stop morph is the single source. **(6) Path truncation in status labels.** New `shortenPaths()` in `StatusHub.svelte` mirrors `EditDiff.shortPath` — verbose `read C:/Users/BLAZZER/Desktop/FiveM Server/...` now shortens to `read .../resources/[endure]/endure_builder/main.lua` so the useful tail stays visible. **(7) Tab bar active indicator.** Active chat tab gets `box-shadow: inset 0 2px 0 0 var(--accent)` — a 2px accent stripe along the top edge so the active tab picks out of the row at a glance. `::before` left untouched since it's reserved for the in-pane (split-mode) marker.
