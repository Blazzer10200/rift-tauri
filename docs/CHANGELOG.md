## v0.14.0 — 2026-06-16 — Chat-page top-right redesign + Environment floating widget

> **Why.** The chat tab-bar's top-right cluster had grown into a cluttered mess: the git branch showed **twice** (header chip + the new Environment surface), the context % showed **twice** (header gauge + composer), and the View menu was a flat grab-bag that mixed navigation, panel toggles, and a layout action as if they were the same kind of thing. This release consolidates each signal to one home and regroups the menu.

**Changed:**
- **Environment is now a floating widget**, not a docked panel — a pill (`⎇ branch +adds −dels`) sits top-right of the chat and auto-shows once the active tab has messages; click expands an in-flow panel that reserves width beside the chat (never overlaps the composer). New [`EnvironmentFloat.svelte`](../src/lib/components/environment/EnvironmentFloat.svelte) owns the git refresh.
- **De-duplicated the header.** Removed the redundant tab-bar branch chip — branch + diff stats now live **only** in the Environment widget and the welcome-card identity unit. Removed the composer's numeric "% context" readout — the header context gauge is the single source of the number; the composer keeps only its ambient divider-fill bar.
- **View menu regrouped** into three labelled sections — *History* (navigation) · *Panels* (Web browser · Sub-agents · Session diff · Environment) · *Layout* (Split pane) — and dropped the no-op checkmarks from the non-toggle rows. Dead CSS removed (`.branch-chip` / `.ctx-readout` / `.vm-sep`).
- **Layout-overlap pass** — the jump-to-latest button now tracks composer height (was hidden behind a tall composer); composer toolbar shrink-guards prevent the send button from being clipped in narrow split panes. The tab-bar action cluster is `flex-shrink:0` over a scrollable tab strip, so width pressure scrolls the tabs rather than clipping the controls.

**Verify.** version lockstep ×3 + `Cargo.lock` · svelte-check 0/0 (4101) · 0 console errors · CDP-verified across populated / empty-pane / 6-tab states.
