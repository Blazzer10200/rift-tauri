## v0.4.18-alpha — 2026-05-20 — S121 Phase 6 OS-keychain + backend HIGH/MED close-out (19 issues)

**Phase 6 — OS-keychain at-rest secrets (3).** Added `keyring = "3"` (Windows Credential Manager / macOS Keychain / Linux Secret Service). New `src-tauri/src/secrets.rs` helper (get/set/delete under service `"rift"`). Per-server `bridge_token` and Anthropic `api_key` now live in the OS keychain; legacy plaintext slots in `~/.rift/rift.json` + `~/.rift/assistant/config.json` are parsed but never re-written. `RiftConfig::load()` + `assistant::load_config()` run one-shot migration on first read (logs `migrated bridge_token for '<key>' to keychain` / `migrated api_key to keychain`), then `skip_serializing_if = Option::is_none` keeps the field absent from disk going forward. `ServerProfilePublic.has_bridge_token` derives from the keychain so `list_servers` still reports configured state correctly. `save_server` writes new tokens straight to the keychain; `delete_server` cleans up the entry. `assistant_send` + `assistant_auth_probe` go through new `current_api_key()` helper. (#37, #9.3) Plus Windows DACL tightening: `write_mcp_config` now runs `icacls /inheritance:r /grant:r <user>:(F)` on the per-session `mcp-config-*.json` so the embedded bridge token isn't readable to SYSTEM/Administrators on domain-joined / shared-profile setups (#38).

**Backend HIGH/MED tail (14).** `AutoSyncStatus` now exposes `dropped_events: u64`; new `fs_events_dropped` field on `DiagStateDto` surfaces it so the diag pump pipes the counter to the UI (#45 closed). `claude_command()` sets `kill_on_drop(true)` so a panicked turn / IPC handle drop kills the CLI child even if `set_session_pid` hadn't completed (#63 closed). `force_pull_now` now retains `ToDeleteRemote` entries when wiping the scan cache post-dispatch so the Sync modal still has remote-delete state to read (#102). Mass-delete circuit-breaker tracks `to_delete_blocked` separately + subtracts before the diag emit (#103). `diag_state_pump` takes a `CancellationToken` via new `DiagPumpCancel` managed state; `RunEvent::Exit` cancels it before `cleanup_mcp_config_on_exit` runs (#106). Shared `collect_diag_dto(Option<Arc<AutoSyncEngine>>)` extracted — `diag_get_state` + the pump share one DTO assembly path so adding a counter requires one edit, not two (#108). New `open_sftp_for_server(&ServerProfile)` variant: `remote_list_dir` already loaded `RiftConfig` for path-guard validation, so passing the server through skips a second `~/.rift/rift.json` parse (#112). `editor_for` race-loss now spawns a background `close().await` on the losing `SftpClient` via `Arc::try_unwrap` — SSH_MSG_DISCONNECT sent promptly instead of waiting for russh GC (#113). `tool_remote_bash` documents the single-thread MCP-server contract so a long bash blocking the JSON-RPC loop is acknowledged design, not a silent regression (#119). `grep` tool's `glob_to_regex` now matches the filename component when the glob has no `/` — `*.rs` finds `src/foo.rs`, not just root-level `foo.rs`; `src/**/*.rs` keeps relpath semantics (#120). `RemoteStateCache::set`/`forget` use new `save_locked(&HashMap)` while the guard is held — no more lock-then-clone-then-relock to write a stale snapshot (#125). `SyncSnapshot::compute_sha1` documented as **BLOCKING** + new `compute_sha1_async` wrapper around `spawn_blocking` (#127). `SftpClient::upload_bytes` documented as internal-only probe (no SETSTAT 0664) (#129). `SftpClient` now has a `Drop` impl: drains the worker `Mutex<Vec<Arc<Worker>>>` synchronously on panic-unwind paths + logs `close().await was not called` when workers leak (#131).

**Hygiene (2).** `atomic_write_json` documented as BLOCKING (Windows rename-retry uses `std::thread::sleep`); callers on the runtime should wrap in `spawn_blocking` for paths likely to hit the AV-scanner retry window (#27). `transport::env::hostname` no longer trusts ambient `$PATH` — tries `COMPUTERNAME` → `HOSTNAME` env → `/proc/sys/kernel/hostname` → `/bin/hostname` / `/usr/bin/hostname` absolute-path probes (#32). #26 (`.gitignore` audit for `Releases/staging-*`) marked non-bug: `Releases/` already covers it. #101 (`recently_written` LRU sweep) marked already-shipped: the 5s root-vanish poll already evicts entries >10s old.

**Verify:** `cargo check` clean (1 pre-existing `private_interfaces` warning in `update_service.rs:199`, unrelated). Frontend `npm run check` untouched this session.
