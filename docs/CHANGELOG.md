## v0.20.2 — 2026-06-17 — Composer caption + slot polish

> **Why.** Two small correctness/visual nits in the composer settings popover surfaced after the v0.20.0 thinking-toggle work, plus a quiet duplication between `toolCaption.basename` and the tabsbar `leafName` that could silently drift.

**Fixed:**
- **Model caption** now reads correctly when Extended thinking is **off** — the model row describes "replies without extended thinking" instead of the stale effort-applies copy, and the ultra-effort `.warn` highlight is suppressed while thinking is off (effort doesn't apply there).
- **Model-row trailing slot** is stabilized — a fixed-width `.model-trail` wrapper holds either the selected ✓ or the numeric shortcut `kbd`, so rows no longer shift width when selection moves.
- **`basename` ↔ `leafName` dedup** — `toolCaption.basename` now mirrors the tested `tabsbar/helpers.ts::leafName` path-leaf logic exactly, with a regression test covering posix/windows/trailing-slash/bare-name so the two siblings can't drift apart.

**Verify.** version lockstep ×3 + `Cargo.lock` · svelte-check 0/0 · vitest 194/194. Frontend-only; backend untouched. Composer visual changes not pixel-verified (CDP wrapper unreachable this session).
