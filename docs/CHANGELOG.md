## v0.4.20-alpha — 2026-05-20 — S123+S124 compaction Phases B-D + live-streaming UX + chat-UI polish

**Conversation compaction — Rift owns it end-to-end** (CLI's `/compact` is interactive-only + user has `DISABLE_AUTO_COMPACT=1` globally). Five phases land in one shipping window.

**Phase B — Summarize primitive.** New `assistant_summarize_session(sessionId, focus, tasksJson) → SummarizeResult` Tauri cmd. Spawns `claude -p "<prompt>" --resume <sid> --output-format stream-json --model haiku --max-budget-usd 1.50 --tools "" --permission-mode bypassPermissions` w/ `CLAUDE_DISABLE_HOOKS=1` (skips 46K-tok SessionStart surcharge → ~$0.05/call savings). cwd pinned to workspace via S98 `.cwd` sidecar. Prompt asks for a 4-section structured summary (Active task / Files in play / Decisions / Open questions) w/ verbatim TodoWrite preservation + explicit drop of tool-call noise. Parser drains `"type":"assistant"` envelopes' `message.content[].text` AND `result.result` as the canonical aggregated text — robust to either CLI output shape (CLI 2.1.139 `-p` mode buffers into the latter; older shapes use per-token deltas). Frontend `AssistantStore.summarizeCurrentSession(focus?)` + `/summarize` debug slash.

**Phase C — Manual compact action.** New `assistant_remint_session(oldSid, newSid)` Tauri cmd (#220 UUID-shape validation; copies the `.cwd` sidecar; leaves old in place for transition-window rollback). `assistant_send` extended w/ `prior_context_summary: Option<String>` — when present, backend pushes *"Prior conversation summary (compacted; the CLI session this turn runs against is fresh — this summary IS your context for what came before):\n{summary}"* into the existing `<system-reminder>` envelope on the next turn. New `BoundaryBlock` synthetic block + `"system"` chat role (additive, 3 edits in `MessageBubble.svelte`). `AssistantStore.compactConversation(focus?)` guards → summarize → mint new UUID via `crypto.randomUUID()` → remint sidecar → push BoundaryBlock → flip `cliSessionId = newSid` + null `convoCreatedAt` → set `pendingCompactionSummary` → resetUsage → save. Header Compact button (visible ≥50% ctx) + `/compact [focus]` slash. MessageBubble renders boundary as a centered pill w/ click-to-expand Markdown.

**Phase D — Auto-trigger + Settings UI.** `AssistantStore.autoCompactThreshold: number | null` + `compactModel: "haiku"|"sonnet"` w/ load on init + persisted setters. Lifted `contextWindowFor/ctxTokens/ctxWindow/ctxPct` from header onto store as derived getters. Auto-trigger `$effect` in AssistantPage.svelte (page-scoped; pauses outside chat workspace). Guards: threshold set, activeTab present, not streaming, not compactingNow, ≥5min since lastCompactionAt, ctxPct ≥ threshold·100. `assistant.compactWarning` getter — warn-toned pre-emption pill in ChatTabsBar when ctx is within 10pp of threshold. Settings → Assistant → new "Conversation compaction" card: threshold `<select>` (Off / 70% recommended / 80 / 85 / 90), Haiku/Sonnet radio ($0.91 vs $2.73 per 900K-tok call), "Compact now" debug button.

**Phase E prerequisites — compactionHistory[] persistence + background-agents tracking.** `CompactionHistoryEntry` type ({at, priorSessionId, newSessionId, summary, costUsd, summaryModel, archivedCount}) on `ConversationRecord` (optional, absent for legacy); hydrated in loadConversation, persisted by buildSaveRecord, pushed on compactConversation success. Backend opaque (serde_json::Value). `TabState.agentSpawns` w/ Task/Agent tool_use → spawn push, tool_result → mark-done; pulsing accent `.agents-pill` in ChatTabsBar shows live count + per-agent tooltip.

**Live-streaming compaction UX.** `assistant_summarize_session` gained `AppHandle`; emits `assistant://summarize-progress {session_id, summary_so_far, status}` rate-limited 150ms/64chars. compactConversation pre-stages the BoundaryBlock w/ `streaming: true` BEFORE the summarize call; per-compact `listen()` filtered by oldSid patches the block's summary in-place as events land. MessageBubble branches on `boundaryBlock.streaming`: pulsing live-dot, "Compacting · N messages · X chars" label, body auto-expanded so user watches summary fill live. On error stale boundary filtered out. CLI 2.1.139 buffers (~150ms streaming window) but the parser also handles per-token deltas for future versions.

**5 live-smoke bugs found + fixed (S123 shipped untested):** (A) summarize spawned w/o `cmd.current_dir(...)` → wrong cwd-hash → "No conversation found"; fixed via `load_session_cwd().filter(|p| p.is_dir())`. (B) stdin-piped prompt ignored — `claude -p` w/ `--input-format text` reads positional arg, not stdin; switched to `cmd.arg("-p").arg(&prompt)` + `Stdio::null()`. (C) NDJSON parser only handled `stream_event/text_delta`; added `"assistant"` branch + `result.result` drain. (D) `scheduleSave.doSave()` unconditionally writes `tab.convoCreatedAt = record.createdAt` and buildSaveRecord falls back to Date.now() when null → clobbered compaction's null-out → next send `isFirstTurn=false` → `--resume` on non-existent JSONL → session-lost recovery → `priorSummary` already drained → summary never delivered; fixed via `TabState.forceNextFirstTurn` flag consumed in send(). (E) duplicate `"stream_event"` match arm; consolidated.

**Chat-UI polish — tool chips redesign + tasks dock progress + streaming heartbeat.** ToolChip gains 5 categories (`read` muted blue / `write` accent / `shell` warm orange / `agent` purple / `meta` green) driving icon color + a 2px left-edge stripe so a wall of chips is scannable at a glance. Inline result preview when collapsed AND result is short (`→ hello from bash`, `→ No files found`). Duration badge (warn pill, e.g. `6.1s`/`2.1s`) when `tool.durationMs ≥ 1000`. Required adding `ToolBlock.startedAt?: number + durationMs?: number` + wiring in appendToolUse/fillToolResult. Pending chips background-pulse. TasksDock 2px progress bar fills as todos complete; pulsing overlay marks the in-progress task. MessageBubble assistant avatar pulses an accent halo while streaming (respects `prefers-reduced-motion`). Chat gap `20px → 16px`. Slash-command picker gains 3 missing entries: `/compact`, `/summarize`, `/openincli`.
