## v0.16.0 — 2026-06-16 — CLI transparency: surface what Claude Code was hiding

> **Why.** The Claude CLI emits stream events that Rift silently dropped — so when Claude Code auto-compacted at the context limit, truncated a response at the output cap, or declined to answer, users saw the conversation "just change" with no explanation ("wtf just happened"). This arc makes those three invisible CLI events visible to *every* user, inline in the transcript, where they happen.

**Added:**
- **Compaction is visible now.** The CLI's `compact_boundary` system event (auto- or manual-trigger) was read for `model` only and the rest thrown away. It now builds a `source:"cli"` `BoundaryBlock` inserted just before the live assistant bubble — a lean, non-interactive "Conversation compacted" pill with a `Ctx X% → Y%` meta and a reassuring tooltip ("Claude Code automatically summarized older messages… nothing on screen was deleted"). Reuses the dormant boundary render path; `microcompact_boundary` is intentionally not surfaced (too noisy).
- **Truncation + refusal notices.** The CLI reports the terminal `stop_reason` in `message_delta`, which the stream pump ignored (it only handled `content_block_*`). `max_tokens` (output hit the length cap) now renders an amber "Response cut off" notice with a one-click **Continue** button on the last turn; `refusal` renders a neutral "model declined" notice. Drives a new `ChatMessage.stopReason` field.

**Changed:**
- **Plain-English run errors.** The `result` error path replaced a terse `KNOWN_ERRORS` set ("Run ended with subtype: error_max_turns") with an `ERROR_MESSAGES` map of human sentences — incl. a recovery hint for `model_context_window_exceeded` ("The context window filled up and couldn't be compacted further. Start a fresh chat to keep going.").
- **View menu tidy.** Removed the `Ctrl⇧B` / `Ctrl⇧D` / `Ctrl\` keybind chips (shortcuts still work) and aligned the menu to the shared `.rift-menu-*` design system (consistent gap/padding, wider min-width). Effort-flag chip in the composer settings menu got a proper inset-token pill.
- **Split-empty-card polish.** The empty split-pane card gained a solid border, entrance animation, accent icon tile, RESUME label + hover chevrons; closing the last tab in single-pane now re-seeds a fresh chat instead of stranding a dead card.

**Verify.** version lockstep ×3 + `Cargo.lock` · svelte-check 0/0 · vitest 33/33 (2 new: `model_context_window_exceeded` hint, `max_tokens` stop-reason flag) · frontend-only (no Rust touched). Live pixel verify was blocked (WebView2 occluded) → DOM-verified the stop-notice + CLI-boundary render paths.
