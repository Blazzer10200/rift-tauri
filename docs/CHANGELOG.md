## v0.20.1 — 2026-06-17 — Thinking-off 400 fix

> **Why.** v0.20.0's cloud thinking-off path 400'd on the first turn: `clear_thinking_20251015 strategy requires thinking to be enabled or adaptive`. The shim forced `thinking:{disabled}` but left the CLI's `clear_thinking_*` context-management strategy in the body — and that strategy is rejected once thinking is off.

**Fixed:** the no-think shim (`assistant/nothink.rs`) now strips any `clear_thinking_*` context-management edit from `/v1/messages` in the same rewrite that disables thinking, then prunes the emptied `edits`/`context_management` so no bare `{}` ships. Structure-agnostic recursive walk — survives CLI schema shuffles. Covers both shim callers (cloud thinking-off **and** local-LLM mode, which could 400 the same way against a strict upstream).

**Verify.** version lockstep ×3 + `Cargo.lock` · `cargo check` clean. Oneshot enhance/title unaffected (spawn the CLI directly, thinking on). Live runtime confirm still pending a dev build.
