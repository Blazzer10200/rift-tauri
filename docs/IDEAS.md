# Rift ideas

Uncommitted product seeds, ordered roughly by value. Revalidate against the live app before planning.

## Near-term

- **Conversation export to Markdown** — export the current local transcript in a durable, readable format without involving a provider.
- **In-transcript find** — a compact match counter and next/previous navigation for long conversations.
- **Prompt snippets** — user-saved prompts exposed through the existing slash menu and a small Settings editor.

## Profile before building

- **Message-list virtualization** — render only the visible transcript window if real long-chat profiles show meaningful DOM or scroll cost. Preserve scroll anchoring and streaming behavior.

## Strategic

- **Provider-neutral update feed** — tracked as issue `#107`; wait for stable official machine-readable OpenAI/Codex sources.
- **Skills browser and runner** — discover and run installed Claude/Codex-compatible skills through a focused GUI without turning Rift into a cockpit.
- **Generative UI** — render safe structured forms, charts, diffs, and approvals inline when a provider emits a supported schema.

Completed palette/search work and retired minimal-core ideas have been removed from this list. Historical context remains in Git and the private design archive.
