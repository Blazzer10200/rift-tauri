# Frontend Audit — 2026-05-11

Scope: state stores + browser/drift/conflict/diagnostics/dialog components.
Skips: anything already covered in `codex-2026-05-11.md` (Rust backend).

| Severity | File:line | Issue | Suggested fix |
|---|---|---|---|
| HIGH | `RemotePane.svelte:44-47` | `$effect` calls `void load()` — async rejection silently swallowed. Stale in-flight `invoke("remote_list_dir")` resolves after path changes and overwrites newer entries. | Propagate rejection (`load().catch(...)`); add destroyed flag in effect cleanup; bail before state writes if destroyed. |
| HIGH | `LocalPane.svelte:44-47` | Same stale-closure + unhandled rejection pattern as `RemotePane`. Rapid nav leaves older `invoke("local_list_dir")` results overwriting newer pane state. | Same fix: destroyed flag, propagate error. |
| HIGH | `AppShell.svelte:95` | `window.addEventListener("keydown", onGlobalKey)` added in `onMount`, removed in `onDestroy`. HMR replacement or component remount leaks the old listener. | Replace w/ `$effect(() => { window.addEventListener(...); return () => window.removeEventListener(...); })`. |
| HIGH | `Diagnostics.svelte:38-49` | `viewport = el.clientHeight` read synchronously inside `$effect` before DOM settles — virtual-scroll may compute start/end indices from 0 on first render, showing nothing until scroll. | Set `viewport` only from `ResizeObserver` callback; remove the synchronous read. |
| HIGH | `connection.svelte.ts:249-321` | `wireEvents()` partial-failure path correctly disposes and rethrows, but the caller (`AppShell.onMount`) has no retry path if `wireEvents` fails. App silently runs with zero Tauri event listeners — status/locks/conflicts/activity all frozen. | Surface `wireEvents` failure in UI (set `lastConnectError`) and expose a retry trigger. |
| HIGH | `DriftReview.svelte:145-154` | `$effect` writes to `selected` ($state) based on `selectableIds` ($derived). Safe today because `selectableIds` does not depend on `selected`, but fragile: any future dep chain closure between them would create a reactive loop. | Derive a `prunedSelected` value instead of imperatively writing to `selected` in the effect; or add a guard comment flagging the constraint. |
| MED | `RemotePane.svelte:89-95` | `rowStatus()` conflict detection matches `c.remote_path` basename against `e.name`. Files in different directories with the same name both show a conflict badge incorrectly. | Use exact path match: `c.remote_path === e.full_path`. |
| MED | `LocalPane.svelte:92-99` | Same basename-only conflict detection as `RemotePane`. | Use `c.local_path === e.path` with OS path normalization. |
| MED | `TwoPane.svelte:41-46` | `toastTimer` (non-reactive `let`) is never cancelled in `onDestroy`. HMR or hot remount leaves a dangling `setTimeout` that fires `toast = null` on the destroyed instance. | `onDestroy(() => { if (toastTimer !== null) clearTimeout(toastTimer); })` |
| MED | `DriftReview.svelte:233-238` | Same `toastTimer` not cleared on destroy. | Same fix: `onDestroy` cleanup. |
| MED | `AppShell.svelte:196-204` | TOFU `$effect` calls `askConfirm()` and chains `.then(connection.confirmFingerprint)` which may execute after the component is destroyed (app close during TOFU dialog). | Capture `let alive = true; onDestroy(() => alive = false)` and guard the `.then()` handler. |
| MED | `diagnostics.svelte.ts:174-181` | `generateReport()` busy-polls `this.events` with `.find()` every 50ms up to 2s. O(n) scan per tick — up to 40 × 1000 = 40K comparisons for a full ring. | Replace poll with a one-shot event listener on `"diag://event"` filtered to `drift_scan_result` stage; resolve immediately when matched. |
| MED | `AddServer.svelte:148-151` | Triple `as unknown as { bridgeToken?; fingerprint?; addedAt? }` cast to extract fields absent from `ServerProfile` type. TypeScript will not catch backend API drift. | Add `bridgeToken?: string \| null; fingerprint?: string \| null; addedAt?: string \| null` to `ServerProfile` type. |
| MED | `connection.svelte.ts:112` | `dirtyEdits = $state<Set<string>>(new Set())` — code correctly creates new Sets on mutation, but the pattern is non-obvious and a future developer mutating the Set in-place would silently break reactivity. | Add `// always replace (new Set(...)), never mutate in place — Set mutations are not reactive` comment. |
| MED | `AppShell.svelte:62-85` | `commands` is `$derived<Command[]>([...])` — entire array (including stable `run` closures) re-creates on every reactive dep change (every status tick). Causes unnecessary `CommandPalette` prop churn. | Split static commands (stable `run`) from dynamic subtitles; use `$derived.by()` to memoize stable refs. |
| LOW | `updates.svelte.ts:20` | `catch {}` silently swallows `app_version` invoke failure; `currentVersion` stays `"?"` with no log. | `catch (e) { console.warn("app_version failed", e); }` |
| LOW | `ConflictResolver.svelte:18-23` | `$effect` resets `pick/error/info` on `conflict.local_path` change, but the parent already uses `{#key selectedConflict.local_path}` which remounts the component fresh. Double-reset is redundant. | Remove the `$effect`; rely on `{#key}` remount for state reset. |
| LOW | `Diagnostics.svelte:17-19` | `onMount` fire-and-forgets `diagnostics.wire()` — if `wire()` is slow, Tauri events emitted before the listener registers are lost. Acceptable given ring-buffer, but undocumented. | Add comment: `// events before wire() resolves are not captured — ring buffer mitigates`. |
| LOW | `DriftReview.svelte:46-51` | `$effect` writes to `subpathsText` ($state) — write-in-effect is unusual and fragile if deps expand. | Add comment: `// writes subpathsText; safe as long as subpathsText is not read by this effect`. |
| LOW | `AddServer.svelte:59-68` | Async IIFE inside `$effect` writes `keyPath` without checking if the component was destroyed before resolution. | Capture `let cancelled = false` and return cleanup `() => { cancelled = true; }` from the outer effect; check before writing. |
| LOW | `AppShell.svelte:98` | `updates.checkOnLaunch()` fired w/ no `await` and no `.catch()`. Internal errors are caught inside `refresh()`, so no unhandled rejection, but failure is invisible to callers. | No change needed; log surfacing handled by the `updates.svelte.ts` LOW above. |
