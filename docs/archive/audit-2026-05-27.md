## Design polish (real but needs a decision)

- **P1 — Composer wider than messages column.** Messages = 1100px centered (x=272→1372). Composer = full 1554px viewport. Visual "T". Either constrain composer to same max-width or widen messages column.
- **P2 — Effort vs model pill affordance mismatch.** Effort pill **cycles on click** (Instant → Smart → Deep) with an inline cache-bust warning. Model pill **opens a dropdown picker**. Two different affordances on adjacent pills.
- **P3 — Asymmetric bubble identity.** Claude bubbles show `Claude · Opus 4.7` header. User bubbles have nothing. Either symmetric "You" label/avatar or strip Claude's header.
- **P4 — History rows all use the same chat-bubble icon.** Aurora already established per-model dot colors (sonnet=blue, opus=purple, haiku=teal). Carry through to history row dots — lets you scan by model.
- **P5 — CLI Session status has no probe-freshness.** Settings → Assistant shows "● Using Claude Code session" with a `Re-probe` button, but no "last checked Xm ago". Stale status indistinguishable from fresh.
- **P6 — Save buttons in Settings → Assistant always look active.** No disabled "no changes" state on Per-turn cost cap or API-key fallback. User can't tell if there's a pending edit.
